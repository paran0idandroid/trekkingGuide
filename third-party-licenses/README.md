# Third-party fonts

## Nohemi

- 用途：全站 `h1`–`h3` 拉丁字符标题
- 文件：`public/fonts/nohemi/*.woff2`
- 来源：Nohemi 作者发布的官方字体包
- 许可：见同目录 `Nohemi-EULA.pdf`

## Satoshi

- 用途：正文、导航和按钮
- 交付方式：通过 Fontshare 官方 Web Font API 加载，不在仓库中保存字体文件
- 地址：`https://api.fontshare.com/v2/css?f[]=satoshi@300,400,500,700&display=swap`

## Noto Sans SC

- 用途：Satoshi 和 Nohemi 的中文回退字体
- 交付方式：通过 Google Fonts 加载，不在仓库中保存字体文件
- 地址：`https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@300;400;500;600;700&display=swap`
