# Decisions — 技术决策记录

## 已确定的决策

### ADR-001: 纯前端 SPA，无后端

**2026-06-14**

所有数据以 TypeScript 模块硬编码在 `src/data/` 中，无后端 / 数据库 / API 依赖。静态资源通过 Vite 构建后部署到 Netlify。

**理由**：
- 内容量适中，不需要数据库
- 部署简单，零运维
- 页面加载快，无网络请求延迟

**影响**：内容更新需要修改源码后重新部署。推荐使用 AI 辅助编辑数据文件。

---

### ADR-002: Tailwind CSS 自定义色板

**2026-06-14**

定义 `forest`（墨绿）和 `sand`（沙色）两个色系，各 9 级（50–900）。

**理由**：
- 与户外徒步主题吻合
- 不需要额外 CSS-in-JS 方案
- Tailwind 的 utility class 覆盖全部场景

**影响**：所有颜色值引用必须走 Tailwind 调和色板（如 `text-forest-500`），不直接写十六进制颜色。

---

### ADR-003: 装备推荐系统 — 纯前端规则引擎

**2026-06-14**

装备推荐不依赖 AI / 外部 API。用纯函数实现匹配逻辑（`src/lib/gearEngine.ts`），产品数据硬编码在 `src/data/gearCatalog.ts`。

**理由**：
- 推荐逻辑可预测、可测试
- 零运行时成本
- 离线可用

**影响**：推荐精度受限于产品数据库规模和规则粒度。需要人工维护产品库。

---

### ADR-004: 中文 UI + 英文代码

**2026-06-14**

UI 文案、URL 路径、注释使用中文。TypeScript 标识符（类型、变量、函数名）使用英文。

**理由**：
- 目标用户为中文徒步爱好者
- 保持代码在编辑器中的可读性和工具链兼容性

**影响**：团队成员需具备双语阅读能力。

---

### ADR-005: 数据与视图分离

**2026-06-14**

路由数据集中在 `src/data/routes.ts` 注册，每条路线的完整数据定义在 `src/data/routeData.ts`。组件只接收 props 或通过 slug 查询数据，不直接持有数据定义。

**理由**：
- 数据可独立测试
- 新增路线只需添加数据文件，不修改组件
- 组件可复用

---

### ADR-006: Vite + React Router v7

**2026-06-14**

使用 `react-router-dom` v7 的 BrowserRouter，不支持 SSR / SSG。

**理由**：
- 内容不需要 SEO 优先（可通过后续添加 sitemap 补偿）
- 开发体验好，热更新快
- 部署到 Netlify 后配合 `_redirects` 文件处理 SPA fallback

---

### ADR-007: WebP 图片格式

**2026-06-14**

所有静态图片使用 `.webp` 格式存放在 `public/pics/`。

**理由**：
- 相比 JPEG/PNG 压缩率高，加载更快
- 所有现代浏览器均支持
