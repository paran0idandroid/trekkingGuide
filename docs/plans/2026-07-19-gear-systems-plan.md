# 六大装备系统模块实施计划

## 实施顺序

1. 用测试锁定六大系统顺序、slug、知识 ID 和产品品类映射。
2. 新增系统数据查询入口与六枚原创内联 SVG。
3. 将装备首页改为六大系统入口，并把路线提示和装备顾问放在入口之后。
4. 新增独立系统详情路由，接入装备选择、三个固定标签和产品参考。
5. 执行 Node 测试、Vite 构建、代码审查、桌面与移动端浏览器 QA。
6. 更新项目文档与 Obliviate 记忆索引。

## 验收标准

- 六个系统入口在桌面、平板和手机端清晰显示。
- URL 能恢复当前系统、装备和标签，浏览器前进后退正常。
- 当前装备内容只显示一个主面板，产品按预算层级分组。
- 现有装备顾问、路线关联、知识详情和背包 3D 功能保持可用。
- 不新增依赖，不使用外部图标素材，不新增未经核验的排行结论。

- ✅ 装备系统相关测试 13 项、全量 Node 测试 43 项通过。
- ✅ Vite production build 与 `git diff --check` 通过。
- ✅ 1440×900 与 390×844 浏览器 QA 通过，控制台无警告或错误。
- ⚠️ 全量 `tsc` 仍有仓库既存的 Three.js、装备顾问空值和 `ImportMeta.env` 类型错误；本次修改文件无新增诊断。
