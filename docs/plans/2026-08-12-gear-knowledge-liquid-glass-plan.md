# 装备知识 Liquid Glass 实施计划

## 实施范围

1. 扩展 Node 静态测试，约束共享环境背景、玻璃层级、顾问配色、键盘交互和辅助显示模式。
2. 将装备知识首页和六大入口接入既有环境背景、玻璃模块与主按钮。
3. 将系统详情的图标、装备导航、分段控件、知识卡、折叠组、产品卡和 3D 操作统一到选择性玻璃层级。
4. 将装备顾问改为浅色玻璃弹窗，保留四步逻辑和遮罩关闭。
5. 运行全量测试、API 测试、生产构建、差异检查及桌面/移动端浏览器 QA。

## 验收结果

- 首页六张卡、详情页三个标签和顾问流程均保持原有数据与路由行为；顾问支持初始聚焦、Tab 循环、Esc 关闭和焦点恢复。
- 1440×900 和 390×844 无横向溢出；所有主要交互目标不小于 44px。
- 移动端装备导航只在桌面断点启用 sticky，避免与正文叠压。
- Node 测试与 Vite production build 通过；完整 TypeScript 检查只剩既有 Three.js 类型声明问题。
