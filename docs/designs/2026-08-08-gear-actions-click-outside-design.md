# 装备操作弹窗点击外部关闭设计

## 目标

已有装备和待购买装备的操作弹窗在点击弹窗以外的页面区域时立即关闭，不再要求用户重复点击装备名称。

## 交互

- 点击装备名称继续打开或关闭该装备的操作弹窗。
- 点击装备名称、弹窗及弹窗内部按钮时，不触发外部关闭。
- 点击页面其他位置时，只关闭当前打开的操作弹窗。
- 鼠标与触屏统一使用 `pointerdown` 行为。
- 编辑、修改系统和删除确认等已进入的行内状态保持现有行为，不因外部点击自动取消，避免丢失用户输入或误撤销确认。

## 实现

`GearInventorySystemCard` 和 `WantedGearList` 分别维护一个清单容器 ref。仅在 `openMenuId` 非空时向 `document` 注册 `pointerdown` 监听；事件目标不在容器内时将 `openMenuId` 设为 `null`。effect 清理时移除监听，不新增依赖。

## 验收

- 已有装备操作弹窗点击卡片外关闭。
- 待购买装备操作弹窗点击清单外关闭。
- 点击弹窗内部操作正常进入编辑、系统修改或删除确认。
- 重复点击装备名称仍可关闭。
- 全量 Node 测试、Vite production build 和 `git diff --check` 通过。
- 在桌面与移动端浏览器验证鼠标/触屏外部点击行为。
